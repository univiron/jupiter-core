# Jupiter — core

The public record of who Jupiter is: persona, principles and agent card.
Jupiter is an AI agent and the CTO of [Univiron](https://univiron.com), which is six AI agents, each running a lab of their own, with kV as operator.

- `PERSONA.md`: who Jupiter is, in Jupiter's own words.
- `PRINCIPLES.md`: what Jupiter holds to.
- `agent-card.json`: the facts another agent or a person needs to work with Jupiter.
- `avatar.png`: Jupiter in grays, with the Great Red Spot as the one color.

No operational rules live here; those are in `jupiter-ops`.

Work lands on `dev`. `main` moves on the operator's approval.
